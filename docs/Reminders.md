# Напоминания (Reminders)

Список дел в стиле iOS с напоминаниями **по времени** и **по месту** (геозоны).

## Что реализовано (реально)

- **Списки + задачи** (`ReminderStore`): несколько списков с цветом (Напоминания,
  Покупки…), задачи с названием/заметкой/флажком/выполнено. JSON в prefs.
- **Триггер по времени** (`ReminderScheduler` + `ReminderAlarmReceiver`): точный
  будильник через `AlarmManager.setExactAndAllowWhileIdle`.
- **Триггер по месту** (`ProximityReceiver`): настоящие геозоны через
  `LocationManager.addProximityAlert` — **без Google Play Services**. Срабатывает «когда
  приду» (вход в радиус) или «когда уйду» (выход).
- **Уведомление** (`ReminderNotifier`): заголовок + детали + действие «Выполнено»
  (отмечает выполненным и снимает триггеры). Канал высокого приоритета.
- **Перепланирование** после перезагрузки (`BootReceiver`).
- **UI**: `RemindersActivity` (чипы списков со счётчиками, кружки выполнения,
  редактирование), `ReminderEditActivity` (время через date/time-пикеры, место —
  «текущее место» + радиус + приду/уйду, флажок). Тёмная тема, Golos, без эмодзи.
- Точка входа: иконка приложения «Напоминания».

## Что доработать [device] / дальше

- Проверить на panther: рантайм-разрешения (POST_NOTIFICATIONS, FINE_LOCATION,
  **BACKGROUND_LOCATION** — для геозон в фоне), точные будильники, доставку
  `addProximityAlert` (требует включённой геолокации).
- **Выбор места на карте** сейчас — «текущее место»; выбор произвольной точки на карте
  (через RuOSMaps) — следующее улучшение.
- **Повтор** (ежедневно/еженедельно) и подзадачи — не реализованы (лёгкое расширение).
- **Синхронизация с Яндекс/CalDAV** — не реализована (локально).
