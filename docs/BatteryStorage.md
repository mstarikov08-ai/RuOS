# Аккумулятор и Хранилище (Settings)

Два экрана в RuOS Настройках на реальных системных данных.

## Аккумулятор (`BatterySettingsActivity`) — реально

- Уровень, состояние (зарядка/разрядка), температура, напряжение, технология —
  из `ACTION_BATTERY_CHANGED`.
- **Здоровье**: «максимальная ёмкость %» = `charge_full / charge_full_design` и число
  циклов — читаются из `/sys/class/power_supply/battery/*` (как делают приложения о
  батарее). Если sysfs недоступен — «недоступно».
- **Режим энергосбережения**: тумблер через `PowerManager.setPowerSaveModeEnabled`
  (откат на secure `low_power`).
- **Расход по приложениям**: через `BatteryStatsManager.getUidBatteryConsumers`
  (реальные мА·ч на uid; рефлексия, т.к. @SystemApi); если привилегия недоступна —
  откат на экранное время за 24 ч (`UsageStatsManager`).

## Хранилище (`StorageSettingsActivity`) — реально

- Всего / занято / свободно — `StorageStatsManager.getTotalBytes/getFreeBytes`
  (откат на `StatFs`), с полосой использования.
- **Категории** и **самые крупные приложения** — `queryStatsForPackage`
  (app+data+cache на пакет).
- **«Можно выгрузить»** — крупные приложения, не открывавшиеся ~30 дней
  (`UsageStatsManager`).

## Что доработать [device]

- `PACKAGE_USAGE_STATS` и `BATTERY_STATS` действуют только на платформенно-подписанной
  сборке (объявлены в манифесте). Проверить на panther чтение sysfs (SELinux),
  `BatteryStatsManager` и размеры приложений.
- **Оптимизация зарядки** (стоп на 80% ночью) — отдельный пункт; требует поддержки
  платформы/демона зарядки, **не реализована** (в дорожной карте).
- Кнопки «Очистить кэш»/«Удалить» из экрана хранилища — следующее улучшение
  (сейчас экран — аналитика).
