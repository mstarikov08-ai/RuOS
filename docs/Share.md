# RuOS Share (обмен файлами по Wi-Fi Direct)

Аналог AirDrop: быстрый обмен файлами и фото между устройствами RuOS поблизости —
**по Wi-Fi Direct, без интернета, проводов и Google-сервисов**.

## Как это работает

- **Приём**: устройство становится автономным **владельцем группы** Wi-Fi Direct
  (`WifiDirect.createGroup`) и слушает `ServerSocket` на стандартном адресе GO
  `192.168.49.1:8988`. Включается тумблером в приложении (foreground-сервис
  `ReceiverService`).
- **Отправка**: из «Поделиться» любого приложения (`SendActivity` — цель share-sheet
  для `SEND`/`SEND_MULTIPLE`, `*/*`) или из самого приложения. Идёт поиск устройств
  (`discoverPeers`), по тапу — подключение к выбранному (`connect`) и отправка файлов
  на адрес владельца группы.
- **Подтверждение приёма**: при входящей передаче `ReceiveServer` читает заголовок и
  **блокирует** поток приёма, пока пользователь не подтвердит во всплывающем окне
  `IncomingActivity` («…хочет отправить N файлов — Принять?»). После согласия файлы
  сохраняются в **«Загрузки/RuOS Share»** через MediaStore с индикатором прогресса.

## Протокол

TCP на порту 8988: первая строка — JSON-заголовок
`{"sender","files":[{"name","size"}]}`, затем подряд байты файлов. Простой,
самодостаточный (`transfer/Transfer.kt`).

## Что требует доработки на устройстве [device]

- **Wi-Fi Direct сильно зависит от устройства/драйвера** — нужно проверять на двух
  реальных panther: discovery, формирование группы, сокет-передачу, рантайм-разрешения
  (`NEARBY_WIFI_DEVICES` на 33+, локация до 33), foreground-сервис типа
  `connectedDevice`.
- **Имя устройства** берётся из `Settings.Global.device_name`/`Build.MODEL`.
- **Шифрование канала** поверх сокета (сейчас полагаемся на WPA2 группы Wi-Fi Direct) —
  возможное усиление.
- **Двунаправленность/докачка** и предпросмотр входящих — следующее улучшение.
