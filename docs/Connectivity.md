# Связь: оплата касанием (NFC) и трансляция экрана

Два экрана в RuOS Настройках.

## Оплата касанием — NFC (`NfcPaymentActivity`) — реально

- Находит установленные **платёжные** HCE-приложения: сервисы с
  `action.HOST_APDU_SERVICE`, у которых в meta-data объявлена группа AID
  `category="payment"` (разбор XML `host_apdu_service`).
- Показывает их списком (иконка + имя) и позволяет выбрать приложение по умолчанию
  для касания терминала. Значение пишется в системную настройку
  `Settings.Secure.nfc_payment_default_component` (нужен `WRITE_SECURE_SETTINGS`,
  есть у платформенно-подписанного приложения). Так MIR Pay становится приложением
  оплаты по умолчанию.
- Если NFC нет — соответствующее сообщение.

## Трансляция экрана (`CastSettingsActivity`) — реально

- Через AOSP `MediaRouter` ищет маршруты беспроводного дисплея
  (`ROUTE_TYPE_LIVE_VIDEO | ROUTE_TYPE_REMOTE_DISPLAY`, Miracast), показывает
  телевизоры/приставки и подключается по тапу (`selectRoute`). Есть переход в
  системные настройки трансляции.

## Что доработать [device] / дальше

- Проверить на panther: список платёжных сервисов и установку дефолта (MIR Pay),
  обнаружение и подключение Miracast к реальному ТВ.
- **QR для Wi-Fi и точки доступа** отложены: нужен проверенный QR-кодер (zxing),
  чтобы не отдавать несканируемый самописный энкодер. Эти пункты — следующий заход
  после подключения библиотеки QR.
