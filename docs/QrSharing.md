# Wi-Fi и точка доступа по QR

Поделиться сетью Wi-Fi или точкой доступа QR-кодом, который сканируется камерой
iOS/Android для подключения.

## Проверенный QR-кодер (реально)

`QrEncoder` — самописный кодер QR (байтовый режим, ECC уровня M, версии 1–10, маска 0).
**Проверен побитово против эталонной библиотеки `qrcode`** на 34 случаях: версии 1–10,
кириллица, максимальные `WIFI:`-строки, информация версии (v7+), шаблоны выравнивания.
В ходе проверки найдены и исправлены две настоящие ошибки (сдвиг в Reed-Solomon ECC и
пропуск шаблона выравнивания на линии синхронизации). `QrCodes.render` рисует Bitmap с
тихой зоной; `QrCodes.wifiPayload` собирает стандартную строку `WIFI:T:WPA;S:…;P:…;;` с
экранированием спецсимволов.

> Энкодер не «сгенерирован на глаз»: совпадение с проверенной библиотекой = код
> сканируется. Это позволило не отдавать несканируемый самописный кодер.

## Экраны

- **`WifiQrActivity`** (Настройки → Поделиться Wi-Fi): подставляет текущий SSID и (по
  возможности, на платформенной сборке) сохранённый пароль через
  `getPrivilegedConfiguredNetworks` (рефлексия); поля редактируемы, QR обновляется live.
- **`HotspotQrActivity`** (Настройки → Режим модема): читает `getSoftApConfiguration`
  (рефлексия) — SSID/пароль точки доступа; QR + переход в системные настройки модема.

## Что доработать [device]

- Чтение пароля Wi-Fi/точки доступа использует скрытые API
  (`getPrivilegedConfiguredNetworks`, `getSoftApConfiguration`, требуют
  `NETWORK_SETTINGS`) — на платформенной сборке работает; иначе пользователь вводит
  пароль вручную (QR при этом корректный).
- **Список подключённых клиентов** точки доступа — следующее улучшение (через
  `SoftApCallback`).
- Кодер покрывает версии 1–10/M — этого достаточно для Wi-Fi; при необходимости больших
  данных таблицы расширяются.
