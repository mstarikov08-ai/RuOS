# RuOS — базовые функции ОС: дорожная карта

Запрошен полный набор «table-stakes» функций уровня iOS 18 (~50 пунктов). Это
работа не на один заход. Ниже — честный статус каждого пункта:

- **✅ Есть** — уже реализовано в RuOS ранее.
- **🆕 Сделано сейчас** — в этом коммите.
- **⏳ AOSP: включить/оформить** — функция есть в Android, нужна активация + тема RuOS
  (не «с нуля»; малый объём).
- **⏳ Построить** — нужен новый код/приложение (отмечен ориентировочный объём).

Всё новое: Golos Text, русский, тёмная тема по умолчанию, пружины, тактильный отклик,
иконки/глифы рисуются (без эмодзи).
