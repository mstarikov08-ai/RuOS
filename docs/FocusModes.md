# Режимы фокусирования (Focus)

Фокус приглушает уведомления от приложений и людей, которых вы не выбрали — как в
iOS 18. Один фокус активен в каждый момент; включается вручную (Настройки →
Фокусирование) или по расписанию.

## Что реализовано (работает)

- **Шесть встроенных режимов**: Не беспокоить, Работа, Личное, Сон, Вождение, Учёба
  (`FocusMode.builtIns()`). Можно редактировать; встроенные нельзя удалить.
- **Создание своих режимов**: имя, нарисованный значок (10 глифов, без эмодзи), цвет,
  список разрешённых приложений, звонки, «полная тишина», приглушение/скрытие на
  экране блокировки, текст автоответа.
- **Фильтрация уведомлений** — главная функция. RuOSFocus рассылает свой фильтр
  (`com.ruos.focus.CHANGED`); `RuOSNotify` (`FocusGate`) при активном фокусе
  показывает баннер и проигрывает звук **только** для разрешённых приложений. Всё
  остальное по-прежнему попадает в Центр уведомлений и считается в бейджах — просто
  не «пробивается». Будильники (`CATEGORY_ALARM`) и, при включённой опции, звонки
  (`CATEGORY_CALL`) проходят всегда. Это в точности поведение iOS Focus.
- **Расписание**: включение/выключение по времени и дням недели, с корректной
  обработкой ночного окна (например, Сон 23:00→07:00). Один точный будильник на
  ближайшую границу + пересчёт после перезагрузки/смены времени
  (`FocusScheduler`, `FocusAlarmReceiver`).
- **Зеркалирование в системный режим «Не беспокоить»** (по возможности): если
  приложению выдан доступ к политике уведомлений, фокус выставляет
  `INTERRUPTION_FILTER_PRIORITY`/`NONE`, чтобы и фреймворк, и сторонние приложения
  затихали. Без доступа — деградирует до тихого no-op, фильтрация баннеров RuOS
  продолжает работать (см. `tools/integrate_into_aosp.sh`, шаг 6f).

## Протокол broadcast

`FocusController` рассылает явный broadcast в `com.ruos.notify` и `com.android.systemui`:

| Действие | `com.ruos.focus.CHANGED` |
|---|---|
| `active` | Boolean — включён ли какой-либо фокус |
| `name` | String — имя активного фокуса |
| `allowed_packages` | StringArrayList — разрешённые пакеты |
| `allow_calls` | Boolean — пропускать звонки |
| `suppress_all` | Boolean — режим «Не беспокоить» (ничего не пропускать) |
| `hide` | Boolean — скрывать беззвучные на экране блокировки |
| `color` | Int (ARGB) — акцентный цвет |

## Что требует доработки (честно)

- **Индикатор фокуса в статус-баре / приглушение экрана блокировки** — broadcast в
  SystemUI отправляется, но приёмник в `RuOSStatusBar`/`LockScreenView` ещё не
  написан (**framework-needed**): нужно добавить отрисовку пилюли с глифом фокуса и
  затемнение keyguard. Сам фильтр уведомлений от этого не зависит и уже работает.
- **Доставка автоответа** — текст автоответа сохраняется и показывается в редакторе,
  но фактическая отправка SMS/в мессенджере требует роли по умолчанию (SMS role) или
  интеграции стороннего приложения (**не реализовано**).
- **Активация по местоположению / «за рулём» по Bluetooth/CarPlay** — в iOS фокус
  может включаться по адресу или подключению к машине. Здесь только расписание
  (**не реализовано**: нужен геофенсинг/детект Android Auto).
- **Отдельные домашние экраны на фокус** — требует поддержки в RuOSLauncher
  (**не реализовано**).
- **Совместное использование статуса фокуса** (как iOS «у пользователя выключены
  уведомления») — требует серверной части мессенджера (**не реализовано**).

## Файлы

- `packages/apps/RuOSFocus/` — приложение (модель, хранилище, планировщик, UI).
- `packages/apps/RuOSNotify/.../service/FocusGate.kt` — фильтр в бэкенде уведомлений.
- Точка входа: Настройки → Фокусирование (и иконка на домашнем экране).
