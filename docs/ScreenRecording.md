# RuOS запись экрана

Из Пункта управления: плитка «Запись» → согласие на захват → обратный отсчёт 3-2-1 →
идёт запись с красным индикатором (время; нажатие — стоп). Повторное нажатие плитки или
действие в шторке останавливает; видео сохраняется в `Movies/RuOS`.

## Что реализовано (реально)

- **`ScreenRecordService`** (foreground, тип `mediaProjection`): запись через
  `MediaProjection` + `MediaRecorder` (H.264, опционально микрофон AAC) в
  `MediaStore` `Movies/RuOS`; виртуальный дисплей; уведомление с «Остановить».
- **`ScreenRecordRequestActivity`** (прозрачная): тоггл — если идёт запись, шлёт стоп;
  иначе запрашивает системное согласие `createScreenCaptureIntent()` и стартует сервис.
- **`RedIndicatorView`**: красная пилюля с пульсирующей точкой и таймером, нажатие —
  стоп. **`CountdownView`**: отсчёт 3-2-1. Glyphs/canvas, Golos, тактильный отклик.
- **Плитка в Пункте управления** (`ControlCenterView`): запускает/останавливает запись;
  становится **красной**, пока идёт запись (через broadcast `com.ruos.screenrecord.STATE`).
- **Микрофон**: поддержан в сервисе; переключается префом (`toggle_mic`).

## Что доработать [device] / следующий шаг

- Проверить на panther: тип FGS `mediaProjection`, запись (даже размеры для кодека),
  отсутствие avc-denials для `TYPE_APPLICATION_OVERLAY` и захвата.
- **Тоггл микрофона жестом**: сейчас флаг хранится в префах; долгое нажатие плитки в ЦУ
  для выбора «Микрофон вкл./выкл.» — небольшой следующий штрих (запуск
  `ScreenRecordRequestActivity` с `toggle_mic=true`).
- **Запись внутреннего звука** приложения (`AudioPlaybackCapture`) — отдельная опция,
  не реализована (микрофон — да).
