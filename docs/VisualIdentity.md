# RuOS — визуальная идентичность (Visual Identity)

Единый премиальный язык на всё: иконки, логотип, загрузка, выключение, зарядка,
предупреждение о низком заряде. Полный свод дизайна — `vendor/ruos/branding/DESIGN.md`.
Эталон: «как будто это сделала компания за миллиард долларов».

## Что входит и где лежит

| Элемент | Источник | Куда ставится |
|---|---|---|
| Дизайн-токены + генератор | `vendor/ruos/branding/gen_branding.py` | — |
| Логотип (знак + надпись) | `vendor/ruos/branding/logo/*.svg` | About, везде |
| 12 иконок приложений (SVG) | `vendor/ruos/branding/icons/svg/*.svg` | мастера |
| 12 иконок (VectorDrawable) | `<App>/res/drawable/ic_launcher.xml` | `android:icon` |
| Контактный лист | `vendor/ruos/branding/preview.png` | предпросмотр |
| Анимация загрузки | `vendor/ruos/bootanimation/bootanimation.zip` | `/product/media` |

| Экран зарядки/«разряжен» | `vendor/ruos/charger/*` | `/system/etc/res/...charger` |

## Иконки приложений

Источник правды — `gen_branding.py`: из одной спецификации он генерирует и SVG, и
Android-`VectorDrawable`, поэтому они не расходятся. Каждая наша иконка — цельный
squircle (iOS-суперэллипс, `n≈5`, радиус ≈22%) с глифом; указана в манифесте через
`android:icon`/`android:roundIcon`, поэтому форма отрисовывается точно, без
маскирования системной формой.

Перегенерация: `python3 vendor/ruos/branding/gen_branding.py` (и `preview.py` для
контактного листа).

## Сторонние приложения — официальные иконки

RuOS **не перерисовывает** иконки RuStore, Яндекса, VK, MAX, MIR Pay, Госуслуг,
RuTube и т.д. Лаунчер рендерит иконку каждого приложения из его APK
(`AppRepository` → `PackageManager.loadIcon`), поэтому официальные иконки
отображаются автоматически. Скрипт `vendor/ruos/tools/pull_thirdparty_icons.sh`
нужен только для QA/маркетингового контактного листа из реальных APK.

> Будущее улучшение (не реализовано): чтобы лаунчер, как iOS, вписывал и сторонние
> иконки в squircle, нужно добавить маскирование в `AppIconView`. Сейчас наши иконки
> уже squircle, сторонние — в своей форме.

## Загрузка / перезагрузка / выключение

- **Логотип загрузки**: чёрный экран, курсивная надпись «RuOS» (наклон 11°) с
  триколором (белый → синий → красный), мягкое свечение — держится, пока система
  грузится. Без спиннера и прогресс-бара (как у Apple).
- **Анимация загрузки** (`bootanimation.zip`): лого плавно пульсирует один раз →
  акцентная черта прорисовывается слева направо → лёгкий мерцающий «шум частиц» →
  устойчивое удержание (зацикленный `part1`), которое SurfaceFlinger плавно гасит в
  экран блокировки, когда система готова. ≈3.3 c + удержание.
- **Перезагрузка**: AOSP показывает анимацию выключения, затем снова `bootanimation`.
  Отдельного «restart»-ресурса в AOSP нет — это нормально.
- **Выключение** (`shutdownanimation.zip`): экран гаснет, лого проявляется, коротко
  держится и плавно исчезает.

Перегенерация: `python3 vendor/ruos/tools/gen_bootanim.py` и `gen_shutdownanim.py`.

## Зарядка и «разряжен» (offline charger)

Рисуется `healthd`/`charger` через `minui`, когда телефон выключен и подключён, или
когда нажали питание на полностью разряженном устройстве.

- `battery_fail.png` — пустой контур батареи с тонкой **красной** полосой снизу +
  «Подключите к зарядке». Показывается на разряженном телефоне.
- `battery_scale.png` — фильмстрип из 5 кадров: **зелёная** заливка растёт с зарядом,
  белая молния, «Зарядка».
- `animation.txt` — сопоставление диапазонов заряда кадрам (формат `healthd`).

Перегенерация: `python3 vendor/ruos/tools/gen_charger.py`.

## Предупреждение о низком заряде (20% / 10%)

`RuOSLowBatteryWarning` (SystemUI): при разряде на 20% и 10% показывает компактную
карточку в стиле iOS — жёлтый глиф батареи (нарисован на canvas, без эмодзи),
«N% заряда осталось» и кнопку **«Режим энергосбережения»** (включает battery saver
через `PowerManager.setPowerSaveModeEnabled`, с откатом на secure-настройку
`low_power`). Пружинное появление, авто-скрытие через ~6.5 c, подавляется при зарядке,
каждый порог — один раз за цикл разряда. Подключается из старта SystemUI
(`RuOSSystemUIModule.initDynamicIsland`).

## Честный объём (что требует доработки на устройстве)

- **Заставка загрузчика (до Android)** — самый первый логотип рисует бутлоадер из
  раздела/прошивки вендора (panther). Его **нельзя** задать оверлеем из этого репо;
  нужно прошить splash в загрузчик. Наш `bootanimation` начинается сразу после.
- **Charger** — формат `animation.txt` и пути (`/system/etc/res` против `/vendor`)
  зависят от конкретной сборки `healthd`/`charger`; кадры и тайминги, возможно,
  потребуют подгонки на panther. Геометрия и изображения финальные.
- **Low-battery** — компонент готов; включение battery saver использует системный API
  (SystemUI платформенно подписан). На устройстве проверить тип окна
  (`TYPE_APPLICATION_OVERLAY`) и отсутствие avc-denials.
- **Шрифт логотипа** — мастер-надпись использует Golos Text (с системным фолбэком);
  кадры `bootanimation` отрисованы тонким гротеском, если Golos-Thin не установлен в
  `vendor/ruos/prebuilts/fonts/GolosText/`.
