# AssistiveTouch (плавающая кнопка)

Управление одной рукой без аппаратных кнопок: плавающая кнопка открывает меню действий
(«Домой», «Назад», многозадачность, Уведомления, Пункт управления, снимок экрана,
блокировка).

## Как это работает (реально)

- **Служба специальных возможностей** `AssistiveTouchService` (`AccessibilityService`) —
  единственный корректный способ выполнять глобальные действия из оверлея. Кнопка —
  оверлей типа `TYPE_ACCESSIBILITY_OVERLAY` (без `SYSTEM_ALERT_WINDOW`).
- **Кнопка** (`FloatingButton`): iOS-овая полупрозрачная «таблетка», перетаскивается по
  экрану (позиция сохраняется), затухает в покое; тап — меню.
- **Меню** (`AssistiveMenuView`): сетка действий с нарисованными на canvas глифами (без
  эмодзи); по нажатию вызывает `performGlobalAction`:
  `GLOBAL_ACTION_HOME/BACK/RECENTS/NOTIFICATIONS/QUICK_SETTINGS`, а также
  `TAKE_SCREENSHOT` (API 30+) и `LOCK_SCREEN` (API 28+).
- **Включение**: приложение «AssistiveTouch» (и Настройки → AssistiveTouch) открывает
  системный раздел спец-возможностей; пользователь включает «RuOS AssistiveTouch».
  Состояние вкл/выкл показывается в приложении.

## Что доработать [device] / дальше

- Проверить на panther: добавление `TYPE_ACCESSIBILITY_OVERLAY`, отсутствие avc-denials,
  работу `performGlobalAction` (особенно `QUICK_SETTINGS` → Пункт управления RuOS).
- **Доквание к краю** и настройка набора действий/прозрачности — следующее улучшение.
- Авто-включение службы по умолчанию можно прописать в
  `Settings.Secure.enabled_accessibility_services` через дефолт продукта (сейчас —
  ручное включение, как требует система).
