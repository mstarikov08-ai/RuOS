# Универсальный доступ (Accessibility)

Экран `AccessibilitySettingsActivity` в RuOS Настройках пишет **реальные** системные
настройки доступности.

## Что реализовано (реально)

- **Жирный шрифт** — Secure `font_weight_adjustment` (0 / 300).
- **Увеличенный контраст** — Secure `high_text_contrast_enabled`.
- **Инверсия цветов** — Secure `accessibility_display_inversion_enabled`.
- **Светофильтры (дальтонизм)** — Secure `accessibility_display_daltonizer(_enabled)`:
  оттенки серого / протанопия / дейтеранопия / тританопия.
- **Размер текста** — System `FONT_SCALE`.
- **Уменьшить движение** — Global `window/transition/animator_animation_scale = 0`
  (отключает анимации переходов).
- **Моно-аудио** — System `master_mono`.
- Ссылки на системный раздел для **экранного диктора (TalkBack)**, **голосового
  управления** и **слуховых аппаратов** — их включение происходит в защищённом
  системном UI.

Записи в Secure/Global требуют `WRITE_SECURE_SETTINGS` (есть у платформенно-подписанного
приложения); каждая операция в `runCatching` с тостом при отказе.

## Что доработать [device] / дальше

- Проверить на panther применение каждого ключа (часть @hide; пишутся строковыми
  именами, т.к. приложение `sdk_version: "current"`).
- **Полноценный русский TalkBack / Voice Access** — это отдельные сервисы AOSP;
  здесь — включение через системный раздел (не дублируем сервис).
- **AssistiveTouch** (плавающая кнопка) и **масштаб экрана (плотность)** — отдельные
  пункты дорожной карты, не входят в этот экран.
