# Действия с выделенным текстом

В меню выделения текста **любого приложения** появляются пункты RuOS, как «Look Up» /
«Translate» в iOS.

## Что реализовано (реально)

- **`SearchTextActivity`** (пункт «Найти») и **`TranslateTextActivity`** (пункт
  «Перевести») зарегистрированы на `ACTION_PROCESS_TEXT` (`text/plain`), поэтому система
  показывает их в панели выделения текста везде.
- Без UI (`Theme.NoDisplay`): читают выделение (`EXTRA_PROCESS_TEXT`) и открывают
  результат в браузере:
  - «Найти» → поиск Яндекса по выделенному тексту;
  - «Перевести» → Яндекс.Переводчик с выделенным текстом (перевод делает сервис —
    мы его не имитируем).
- **Лупа выделения** (magnifier) и «Скопировать/Вставить/Поделиться» — штатные в AOSP.

## Что доработать / дальше

- **Офлайн-перевод** и встроенная карточка перевода — требуют движка перевода
  (ML Kit/собственная модель); сейчас честно открывается веб-переводчик.
- «Найти» использует Яндекс; можно сделать выбор поисковика в настройках.
