# Экстренный вызов (SOS) и Медкарта

Безопасность как в iOS: экстренный вызов 112 с обратным отсчётом и оповещением близких,
плюс медкарта, доступная с экрана блокировки.

## Что реализовано (реально)

- **Медкарта** (`MedicalIdEditActivity` / `MedicalIdViewActivity`, `EmergencyStore`):
  имя, дата рождения, группа крови, рост/вес, донорство, аллергии, заболевания,
  лекарства, примечания + список экстренных контактов. Просмотр помечен
  `showWhenLocked` — данные видны спасателям **без разблокировки** (как iOS Medical ID).
- **Экстренные контакты**: добавление/удаление; на экране медкарты — кнопка «Позвонить».
- **SOS** (`SosActivity`, `showWhenLocked`): 5-секундный обратный отсчёт с громким
  сигналом и вибрацией → авто-вызов **112** (`ACTION_CALL`, иначе `ACTION_DIAL`), затем
  SMS экстренным контактам с текстом «Мне нужна помощь» и ссылкой на карту с
  местоположением (`EmergencyActions`).
- Точки входа: иконка приложения «Медкарта и SOS», Настройки → «Экстренный вызов — SOS».
- Тёмная тема, Golos, без эмодзи.

## Что доработать [device] / дальше

- **Аппаратный триггер** (5× кнопка питания / удержание питания+громкость) — это
  `PhoneWindowManager` в system_server; нужно направить chord на запуск `SosActivity`
  (как сделано для двойного нажатия → MIR Pay). Сейчас SOS открывается из приложения,
  медкарты и (по доработке) с экрана блокировки.
- **Кнопка на keyguard**: `RuOSAuth` LockActivity должна показывать «Экстренный вызов»
  и «Медкарта», запускающие эти `showWhenLocked`-экраны без разблокировки — небольшая
  следующая правка.
- Проверить на panther: `CALL_PHONE`/`SEND_SMS`/локацию (рантайм), авто-вызов 112.
