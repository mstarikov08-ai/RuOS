# RuOS Связка ключей (Keychain)

Менеджер паролей с шифрованием, системным автозаполнением и встроенным генератором
кодов двухфакторной аутентификации (TOTP) — аналог iCloud Keychain.

## Что реализовано (реально)

- **Шифрованное хранилище** (`Vault` + `KeychainStore`): весь сейф (логины + TOTP-секреты)
  сериализуется в JSON и шифруется **AES-256-GCM** ключом из AndroidKeyStore
  (аппаратный, не покидает устройство, вне бэкапов). В открытом виде ничего не лежит.
- **Автозаполнение** (`RuOSAutofillService`): находит поля логина/пароля в любом
  приложении, предлагает сохранённые данные. Датасеты **за биометрией** —
  response-level authentication: нажатие на подсказку открывает `AutofillUnlockActivity`
  (Face ID / код), и только после успеха пароли расшифровываются и подставляются.
  При вводе новых данных система предлагает сохранить их (`SaveInfo`).
- **TOTP 2FA** (`Totp`): честный RFC 6238 (HMAC-SHA1, окно 30 c, 6 цифр). Добавление —
  вставкой `otpauth://`-ссылки или вручную (Base32-секрет проверяется генерацией кода).
  Живые коды с кольцом обратного отсчёта (`TotpRowView`).
- **UI** (`KeychainActivity`, биометрический вход): вкладки «Пароли» и «Коды»;
  просмотр/правка логина с показом и копированием пароля; добавление/удаление. Тёмная
  тема, Golos, без эмодзи.
- Точка входа: Настройки → Пароли, плюс иконка приложения.

## Включение автозаполнения

Выберите RuOS как сервис автозаполнения (Настройки → Автозаполнение), либо:

```
adb shell settings put secure autofill_service \
  com.ruos.keychain/com.ruos.keychain.autofill.RuOSAutofillService
```

## Что доработать [device] / дальше

- Проверить на panther: привязку `BIND_AUTOFILL_SERVICE`, парсинг `AssistStructure`
  на реальных формах, подстановку и диалог сохранения.
- **Сопоставление по веб-домену** для браузеров берёт `webDomain` узла; уточнить
  нормализацию доменов (сейчас простое вхождение по подстроке).
- **Сканирование QR** для добавления 2FA (сейчас — вставка `otpauth://` и ручной ввод):
  небольшой следующий штрих через камеру.
- **Синхронизация** между устройствами (E2E) — не реализована; сейф локальный.
- **Генератор паролей** при создании записи — лёгкое следующее улучшение.
